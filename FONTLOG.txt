FONTLOG for Buena Mono
======================

This file provides detailed information on the Buena Mono font software. This
information should be distributed along with the Buena Mono fonts and any
derivative works.


Basic Font Information
----------------------

Buena Mono is a writer-first monospace typeface — tuned for extended prose in
markdown and code editors while keeping code legible. It is a two-axis variable
font: weight 100–800 and slant 0 to −10°, from 8 masters, covering 5,406 glyphs
(Latin incl. Extended A–D, Greek, Cyrillic, IPA, math, arrows, box-drawing,
block/shade elements and currency), with code ligatures and 12 stylistic sets.

Buena Mono is built on Fragment Mono (SIL Open Font License 1.1) by Wei Huang,
and extended into a variable family.


ChangeLog
---------

28 Jul 2026 (Buena) Buena Mono Version 1.231
- Chess pieces U+2654-265F retraced from the author's own reference silhouettes
  (sources/references/chess/), replacing the v1.230 parametric redraw. The chess
  art is original to the author and licensed under the OFL with the font — no
  third-party outlines are bundled.

28 Jul 2026 (Buena) Buena Mono Version 1.230
- Chess pieces U+2654-265F redrawn in a flat/modern style (BUENA-347).
- Board-game glyphs: go stones, draughts, go-board points, watch, hourglass
  (U+26AA/26AB, U+26C0-26C3, U+2686-2689, U+231A/231B; BUENA-349).
- Music: whole/half/quarter rests (U+1D13B-D) + dingbats cut-time, segno, coda,
  fermata, repeat barlines (U+1D135, U+1D10B/C, U+1D110, U+1D106/7; BUENA-348).
- 5,406 glyphs (+21). fontspector googlefonts: 0 FATAL / 0 FAIL.

3 Jul 2026 (Buena) Buena Mono Version 1.218
- Initial public release.
- Two-axis variable font (weight 100–800, slant 0 to −10°), 8 masters.
- 4,857 glyphs; code ligatures; 12 stylistic sets (ss01–ss12).
- OpenType: ccmp, mark, mkmk, aalt, calt, liga, smcp, ss01–ss12.
